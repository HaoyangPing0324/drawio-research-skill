# Revision playbook

Translate feedback into a measurable action rather than applying generic beautification.

| User feedback | Diagnose | Revise | Verify |
|---|---|---|---|
| Too wide | Long labels, inter-stage gaps, blank right edge | Repack groups, shorten redundancy, narrow last column, crop | Occupied width reduced; text scale and arrow shafts preserved |
| Too tall | Repeated header/caption bands, nested cards | Merge bands, reduce nesting, use reasoning strips | Physical height reduced without panoramic width |
| Too sparse | Oversized containers, unused bands | Fit boxes, align baselines, relocate connected groups | Whole-image balance; no random filler |
| More small elements | Missing visual explanation | Add a meaningful tensor/PE/FIFO/report motif where supported | Each addition has a named role |
| Added meaningless things | Decorative marks or invented objects | Delete them and reclaim their space | Content inventory contains every remaining object |
| Arrows are messy | Competing reading orders, oversized return bus | Separate main/secondary paths, simplify fan-out | No ambiguity, hidden shafts, or accidental junctions |
| Arrows are too short | Head or label consumes the shaft | Move groups apart locally or shorten label | Visible run at final print scale |
| Text touches frames | Wrap, thickened border, font substitution | Resize label/container or reword precisely | Rendered text/frame check and crop |
| Colors look artificial | Saturation, too many unrelated fills | Extract a restrained reference palette | Grayscale and semantic consistency |
| Lines look artificial | Every mark equally thick; nested frames | Use a frame/flow/wire hierarchy | Main hierarchy clear; detail subordinate |
| Make borders heavier | Stroke encroaches on content | Increase main frame only, then adjust inner padding | No new contacts after export |
| Separate logos and text | Wordmarks embedded in raster | Use verified symbol plus editable name | No double naming, no distorted logo |
| I cannot understand it | Icons lack labels or relations are unclear | Rewrite one-sentence message, relabel, simplify topology | A reader can explain the flow without the manuscript |
| Keep content, make smaller | Requested size conflicts with text density | Remove redundancy, repack, reduce repeated motifs | Mandatory content checklist and physical type size |

## A practical rejection log

Record the actual defect, its cause, the corrective edit, and the new evidence. Example: "Co-design caption wrapped into the PE array and footer; replaced repeated wording with a shorter unambiguous label; fresh SVG contact check and PDF raster review passed." Avoid vague entries such as "made it prettier."

## Prevent regressions

After a style change, check text padding. After a text change, check wrapping. After a box move, check terminals and waypoints. After a crop, check arrowheads and export bounds. After a PDF conversion, check every label. After a user-approved layout, constrain future edits to the requested scope unless the user explicitly allows broader redesign.

## Conflicting preferences

Minimal spacing and zero overlap must coexist; "fill all whitespace" is a density preference, not permission to create meaningless marks. Thick borders and tiny output size must coexist; do not increase all internal wire weights with the outer frame. More pictograms and clear meaning must coexist; a labelled semantic schematic is better than a decorative collage. When a real trade-off remains, explain it concretely rather than quietly sacrificing content or readability.
